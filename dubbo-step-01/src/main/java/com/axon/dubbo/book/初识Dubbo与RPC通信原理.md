# 📘 第一章 初识Dubbo与RPC通信原理

## 一、Dubbo 背景简介

Dubbo 是阿里巴巴开源的高性能 Java RPC 框架，广泛应用于微服务架构中。它的目标是让开发者更专注于业务开发，而无需关心服务间通信的底层实现细节。

Dubbo 支持：

* 点对点的高效 RPC 通信（TCP + NIO + 自定义协议）
* 多协议、多注册中心
* 服务注册发现、负载均衡、容错策略
* 拓展能力强（SPI 插件化架构）

## 二、RPC 通信原理

### 1. RPC（Remote Procedure Call）定义

> RPC 是一种跨进程通信方式，它允许调用远程主机上某服务的函数，就像调用本地函数一样。

本质上它包含以下几步：

1. 客户端调用本地代理方法（接口）
2. 本地代理将方法名、参数封装为请求报文
3. 客户端通过网络发送报文给服务端
4. 服务端接收报文，解码，调用对应服务方法
5. 返回结果给客户端，客户端解码返回

### 2. RPC 基本组成

| 组件            | 说明                         |
| ------------- | -------------------------- |
| Proxy         | 客户端本地代理类，调用时封装请求           |
| Protocol      | 通信协议，负责编解码与传输              |
| Invoker       | 抽象的执行器，统一调用方式              |
| Registry      | 注册中心，负责服务注册和发现             |
| Transport     | 网络通信层，封装 Socket/Netty 传输   |
| Serialization | 序列化协议，如 JDK、Hessian、JSON 等 |
